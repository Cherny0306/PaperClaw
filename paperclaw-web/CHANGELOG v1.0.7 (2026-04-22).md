# PaperClaw Web UI 更新日志

## v1.0.7 (2026-04-22)

### 新功能：批量删除运行记录

**功能特性**：
- ✅ 批量选择模式 - 一键进入批量管理界面
- ✅ 复选框选择 - 点击卡片或复选框选择多个运行
- ✅ 全选/取消全选 - 快速选择所有可删除的运行
- ✅ 智能过滤 - 自动排除正在运行的任务（不可删除）
- ✅ 批量删除确认 - 显示删除数量并要求确认
- ✅ 删除结果反馈 - 显示成功/失败统计和详细错误

### 前端改动

**Dashboard.tsx**：
- 新增状态管理：
  - `selectedRuns` - 跟踪选中的运行记录
  - `isBulkDelete` - 控制批量删除模式

- 新增函数：
  - `toggleSelectRun()` - 切换单个运行的选择状态
  - `toggleSelectAll()` - 全选/取消全选
  - `handleBulkDelete()` - 批量删除处理

- 新增UI组件：
  - 批量管理按钮栏
  - 全选按钮
  - 批量删除按钮（显示选中数量）
  - 取消按钮
  - 每个卡片上的复选框

**App.tsx**：
- 新增 `handleDeleteMultiple()` 函数
- 支持批量删除多个运行记录
- 逐个调用后端API删除
- 收集成功/失败统计
- 显示详细的删除结果报告

**Dashboard.css**：
- 新增批量操作按钮样式
- 新增复选框样式
- 新增选中状态的卡片样式（高亮边框）
- 批量模式下的卡片样式调整
- 批量模式下的隐藏删除按钮

### 功能流程

```
进入批量管理
    ↓
点击"批量管理"按钮
    ↓
显示批量操作栏：
  - 全选按钮
  - 批量删除按钮（显示选中数量）
  - 取消按钮
    ↓
每个卡片显示复选框
    ↓
用户选择运行记录：
  - 点击复选框
  - 或点击整个卡片
    ↓
点击"批量删除"按钮
    ↓
显示确认对话框（删除数量）
    ↓
用户确认
    ↓
逐个删除选中的运行
    ↓
显示删除结果：
  - 成功数量
  - 失败数量
  - 详细错误列表
    ↓
退出批量管理模式
```

### UI设计

**批量操作按钮栏**：
```
┌─────────────────────────────────────────────┐
│ Recent Runs                                 │
│                                             │
│ [批量管理]                                   │
└─────────────────────────────────────────────┘
```

**批量管理模式**：
```
┌─────────────────────────────────────────────┐
│ Recent Runs                                 │
│                                             │
│ [全选] [删除选中 (3)] [取消]                 │
└─────────────────────────────────────────────┘
```

**卡片样式**：
- 普通模式：右上角显示删除按钮（✕）
- 批量模式：左上角显示复选框
- 选中状态：蓝色高亮边框 + 浅蓝色背景
- 禁用状态：复选框置灰（正在运行的任务）

### 智能过滤

**自动排除不可删除的任务**：
- 正在运行的任务（status === 'running'）
- 全选时会跳过这些任务
- 复选框显示为禁用状态

### 删除结果反馈

**全部成功**：
```
成功删除 5 个运行记录
```

**全部失败**：
```
删除失败！

pc-20260422-001: 正在运行，无法删除
pc-20260422-002: 未知错误
```

**部分成功**：
```
批量删除完成：
成功: 3 个
失败: 2 个

失败详情：
pc-20260422-004: 正在运行，无法删除
pc-20260422-005: 网络错误
```

### 使用示例

**场景 1：删除所有失败的任务**
```
1. 点击"批量管理"
2. 点击"全选"（自动跳过运行中的任务）
3. 点击"删除选中 (N)"
4. 确认删除
```

**场景 2：选择性删除**
```
1. 点击"批量管理"
2. 逐个点击要删除的卡片（或复选框）
3. 点击"删除选中 (N)"
4. 确认删除
```

**场景 3：取消批量操作**
```
1. 点击"批量管理"
2. 选择了一些运行
3. 改变主意 → 点击"取消"
4. 返回正常模式
```

### 交互细节

**复选框交互**：
- 点击复选框：切换选中状态
- 点击卡片（批量模式）：切换选中状态
- 复选框的点击事件不会触发卡片的点击事件

**按钮状态**：
- "批量管理"：有运行记录时启用
- "全选"：有可删除运行时启用
- "删除选中"：有选中项时启用，显示选中数量
- "取消"：始终可用

**视觉反馈**：
- 选中的卡片：蓝色边框 + 浅蓝色背景
- 复选框：使用浏览器默认样式 + accent-color
- 按钮：悬停效果、禁用状态

### 性能优化

- 批量删除使用 `Promise.all` 并行请求（未来可优化）
- 删除成功后立即更新前端状态
- 清理 localStorage 只执行一次

### 已知限制

- 批量删除时是逐个调用API（串行），可能较慢
- 没有进度条显示删除进度
- 删除失败的运行会保留在列表中
